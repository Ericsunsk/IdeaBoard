## Manifest rules

- Add one row per moved, renamed, merged, or deleted production module before changing it.
- `import_consumers` must be verified from the dependency graph, not guessed from directory names.
- `contract_impact` must reference `frontend-contract-inventory.md` when non-empty.
- Unresolved ownership, repository, sync, public API, schema, or storage ambiguity blocks the phase.
