# ADR-NNNN: Short Decision Title

## Context

说明这个 decision 为什么必要：当前 situation、constraint 或 trade-off 是什么。必要时
链接相关 `DESIGN.md`、`CONTEXT.md`、issue 或 runbook。

## Decision

直接写我们决定了什么，包括后续改动必须守住的 boundary 或 rule。

## Consequences

说明这个 decision 让什么变得更容易、更困难，或哪些方向被有意排除。只有当
follow-up work 属于 decision 的一部分时，才写进来。
