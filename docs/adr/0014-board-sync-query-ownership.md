# Board Sync 的 Query ownership（P2.5 六项设计）

## Context

计划 §3.4 / §5.7 要求六项 Sync 决策分别由 plan owner 接受，设计和永久 regression specs 合并后才能启动 P3。本 ADR 是待接受的设计；本地验证、plan-owner acceptance、merge 与 CI 是独立状态。执行状态及证据只记录在 [canonical migration ledger](../architecture/frontend-contract-inventory.md) 的 `behaviors` 与 `syncDesign`，本文不替代 acceptance 或授予 P3 启动权限。

`features/board/testing/syncDesignHarness.ts` 是永久 specs 使用的 private test-only executable design harness，通过真实 TanStack Query observers、HTTP adapter 和 workspace SSE subscription 保存 thin-slice spike 结论。它未接入 production repository，也未导出到 production barrel；其绿色结果证明设计行为，不证明 P3 production Query 迁移完成。当前 production catalog 与 document state 仍由 `application/catalog`、`application/sync` 和 persistence store 管理；P3 才迁移 server snapshot ownership。

[ADR-0006](./0006-board-optimistic-revision-concurrency.md) 已 deprecated，仅 optimistic revision concurrency invariant 仍有效；它记录的 `base_revision` / `new_revision` wire encoding 已废弃。当前 `If-Match` / HTTP 409 contract 来自 `apps/api/openapi.public.yaml`、`DESIGN.md` 和 `features/board/infrastructure/api/boardsResource.ts`，本 ADR 不改变该 wire contract。

下表的 spec 路径以 `apps/web/src/features/` 为前缀。每项 verification 引用 canonical ledger 中对应 `behaviors[id].evidence` / `verifiedRun` 和 `syncDesign.evidence`；对应 gate 的 acceptance 仍待 plan owner 独立记录。

## Decision

### 1. Source of truth

P3 目标：TanStack Query 拥有 catalog list 和每个 board 的 server document snapshot；feature-owned store 拥有 draft overlay。selection port 提供 scope，缺少 workspace 时在任何 network call 前 fail closed。Query key 只允许 `['boards', workspaceId, 'list']` 与 `['boards', workspaceId, 'board', boardId, 'document']`，scope root 为 `['boards', workspaceId]`。Canvas 使用 draft-overlay view；gallery 使用 server catalog view，不为 thumbnails 获取完整 document。

### 2. Stale/gc timing

catalog list 使用 `accountScoped` preset（stale 15s）；document 继承 global default（stale 5s）。`gcTime` 10m、`retry 1` 继续继承 singleton `queryClient` defaults；production feature 不创建第二个 QueryClient。

### 4. SSE-to-Query mapping

SSE 仅提供 invalidation signal。`board.document_replaced` 经 500ms coalesce 后 invalidate document；revision 小于或等于 observed revision 的 frames 丢弃；draft-dirty board 只 mark stale，不 refetch、不覆盖 draft。`board.member_changed` invalidate list；`board.share_revoked` invalidate list 并 remove document query。gap 仅 invalidate `['boards', workspaceId]` scope root，其他 workspace 与 tasks cache 保持不变。event 即使含意外 document 字段也不作为 snapshot 使用；SSE 禁止对 document content 调用 `setQueryData`。未来 optimistic `setQueryData` 仅限 create/rename local write-back。

| 字段                        | 决策与证据                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Owner                       | Board invalidator；Workspace event transport                                                                                                                                                                                                                                                                                                                                                                                                              |
| Active spec                 | `board/application/sync/boardSseMapping.contract.spec.ts`                                                                                                                                                                                                                                                                                                                                                                                                 |
| Scenario / observable check | `invalidates the document on document_replaced with 500ms coalesce`：500ms 前不 refetch，多帧仅新增一次 HTTP read；`drops document_replaced frames at or below the local revision`：旧/重复 frames 不 refetch；`marks draft-dirty boards stale without refetching or overwriting the draft`：stale 为 true，request count 与 draft 保持；member/share/gap active scenarios 分别断言 list-only、document removal、scope isolation 与 `setQueryData` 未调用 |
| Verification evidence       | `behaviors[id=sync-design/sse-broadcast]`；`syncDesign.evidence`；gate `P2.5/SYNC-SSE`                                                                                                                                                                                                                                                                                                                                                                    |

### 5. Revision coexistence 与 404

document save 将 observed revision 作为 `If-Match`。HTTP 409 保留 draft 与 base revision，并维持 conflict classification，直至显式 reload 收敛。archived write 使用 banner path，不进入 revision-conflict path；rename 仅 PATCH name，不写 document，并采用 server-advanced revision。

document PUT 404 不触发 create 或 upsert，保留 local draft 和已有 base revision（never-synced draft 保持无 revision）。document GET 404 使整个 hydrate 返回失败，保留 draft 与 revision；只有成功取得的完整 catalog list 确认远端 absence 时才移除 previously synced board，never-synced offline creation 继续保留。

| 字段                        | 决策与证据                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Owner                       | Board Sync 与 API adapter                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Active spec                 | `board/application/sync/boardRevisionConflict.contract.spec.ts`                                                                                                                                                                                                                                                                                                                                                                                              |
| Scenario / observable check | `keeps the draft and the conflict status on 409, then converges on explicit reload`：409 后 draft/base revision 保留，reload 后采用 remote winner；`preserves the $label draft when the document PUT returns 404`：两种 revision 状态下单次 PUT、无 POST/upsert、draft/revision 保留；`preserves drafts on document GET 404 until a complete list confirms remote absence`：GET 404 hydrate 失败且保留两类 draft，完整 list absence 后仅 synced board 被移除 |
| Verification evidence       | `behaviors[id=sync-design/revision-conflict]`；`syncDesign.evidence`；gate `P2.5/SYNC-REVISION`                                                                                                                                                                                                                                                                                                                                                              |

| Acceptance                  | Pending plan-owner acceptance；当前 transport regression 不能替代 P3 production Query integration verification                                                                                                                                                                                                                                                                                                                                               |

### 6. Local-draft overlay precedence

local-newer draft 优先于旧 remote snapshot；显式 rollback 或 `preserveLocalNewer: false` 才收敛到 remote snapshot。never-synced offline creation 保留，完整 list 确认 deleted-elsewhere 的 synced board 才移除。overlay 固定到请求捕获的 scope，workspace switch 后丢弃 late response。Canvas 显示 draft overlay，gallery 显示 server catalog；P3 实现 Query ownership 后保持相同优先级。

| 字段                        | 决策与证据                                                                                                                                                                                                                                                                                                                                                                                                              |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Owner                       | Board store 与 hydrate sync boundary；Canvas 保持 draft-overlay view                                                                                                                                                                                                                                                                                                                                                    |
| Active spec                 | `board/application/sync/boardDraftOverlay.contract.spec.ts`                                                                                                                                                                                                                                                                                                                                                             |
| Scenario / observable check | `lets the local-newer draft win over an older remote snapshot`：local name/content 保留；`lets an explicit rollback converge to the remote snapshot`：remote name/content 替换；`keeps never-synced offline creations and drops deleted-elsewhere boards`：offline 保留且 synced absence 移除；`freezes the overlay to the captured scope: a workspace switch drops the late response`：hydrate 失败且新 scope 内容保持 |
| Verification evidence       | `behaviors[id=sync-design/draft-overlay-precedence]`；`syncDesign.evidence`；gate `P2.5/SYNC-DRAFT-PRECEDENCE`                                                                                                                                                                                                                                                                                                          |
| Command                     | `cd apps/web && npm run test:run -- src/features/board/application/sync/boardDraftOverlay.contract.spec.ts`                                                                                                                                                                                                                                                                                                             |
| Acceptance                  | Pending plan-owner acceptance；现有 store regression 与 P3 Query binding 分开记录                                                                                                                                                                                                                                                                                                                                       |

### P3 red/green trio 冻结

以下 test locator、scenario 和 observable assertions 是 P3 必须保留的 trio。当前 design harness green 只属于 P2.5 本地 design verification。P3 开始后，先将这些 scenarios 绑定实际 production Query boundary，运行并记录 implementation 前的真实 red，再实现迁移并以相同 command 记录 green；不得通过 skip、固定字符串比较或继续调用 private design harness 声称 production green。conflict 的当前 transport assertions 已为 green，P3 的 red 必须覆盖新增 production Query integration，而不能伪造现有 transport failure。

| Ledger behavior ID                     | 固定 test locator / scenario                                                                                                                                                  | 必须保留的 observable assertions                                                                                                                                                                                                                                                |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `board/query-migration-trio-race`      | `apps/web/src/features/board/application/sync/boardSourceOfTruth.contract.spec.ts` → `cancels the old workspace read and ignores its late response after observer navigation` | old request 的 `AbortSignal.aborted === true`；old workspace document cache 为 undefined；observer 保持新 workspace revision 9 和 `other workspace` 内容；总 HTTP requests 为 2                                                                                                 |
| `board/query-migration-trio-broadcast` | `apps/web/src/features/board/application/sync/boardSseMapping.contract.spec.ts` → `invalidates the document on document_replaced with 500ms coalesce`                         | 499ms 时仍仅 1 request / revision 7；500ms 时仅新增 1 request，HTTP snapshot 为 revision 10 / `latest from HTTP`；SSE 不调用 `setQueryData`；辅助 scenario `marks draft-dirty boards stale without refetching or overwriting the draft` 断言 stale、无 refetch、draft 保留      |
| `board/query-migration-trio-conflict`  | `apps/web/src/features/board/application/sync/boardRevisionConflict.contract.spec.ts` → `keeps the draft and the conflict status on 409, then converges on explicit reload`   | 409 后 `revision-conflict`、local draft 与 base revision 7 保留；显式 reload 后 revision 8 / remote winner；辅助 scenario `preserves drafts on document GET 404 until a complete list confirms remote absence` 断言 GET 404 不删除 draft，完整 list absence 只移除 synced board |

每个 scenario 的 red 和 green 执行 command 相同，分别记录不同 production tree 的结果、checkpoint 和 artifact fingerprint；canonical 记录位于 `syncDesign.p3Trio`，production status 在实际绑定和 red/green 完成前保持 pending。

```sh
cd apps/web
npm run test:run -- src/features/board/application/sync/boardSourceOfTruth.contract.spec.ts -t 'cancels the old workspace read and ignores its late response after observer navigation'
npm run test:run -- src/features/board/application/sync/boardSseMapping.contract.spec.ts -t 'invalidates the document on document_replaced with 500ms coalesce'
npm run test:run -- src/features/board/application/sync/boardRevisionConflict.contract.spec.ts -t 'keeps the draft and the conflict status on 409, then converges on explicit reload'
```

## Consequences

`search`、`canvas` 与 `library` 保持 Query ban。六项 decision 的 local verification、独立 review 和 plan-owner acceptance 必须在 canonical ledger 分开记录；所有 P2.5 exit gates 接受并合并后才能启动 P3。新的 board key root、freshness/gc policy、focus path、SSE snapshot payload、revision wire encoding 或 draft precedence 变化都触发设计 review；后续 accepted ADR 应明确 supersede 本记录。

## Status

Proposed。六项设计的受委托独立 review 已通过；named plan-owner acceptance、历史 before-start green CI checkpoint 与前置 phase 验收仍需在 canonical ledger 完成。设计及永久 specs 已进入本地 `main`；private executable test helper 保存 spike 结论，production Query 迁移仍未合入。
